# Prompts rápidos do Codex

Use estes dois prompts em qualquer nova sessão do Affiliate Intelligence Hub. O [manual mestre](docs/PROJECT_MASTER_GUIDE.md) contém todos os requisitos; o [status](docs/PROJECT_STATUS.md) registra o progresso.

## 1. Recuperar contexto

```text
Leia o arquivo docs/PROJECT_MASTER_GUIDE.md e execute o prompt de recuperação de contexto definido nele.

Identifique a fase atual do projeto, as funcionalidades implementadas, as pendências, os riscos e a próxima fase do roadmap.

Considere o código existente e o docs/PROJECT_STATUS.md como fontes do estado atual.

Não realize alterações. Apresente seu diagnóstico e aguarde minha autorização.
```

## 2. Autorizar a próxima fase

```text
Autorizo a execução da próxima fase identificada.

Utilize o prompt correspondente e as regras comuns disponíveis em docs/PROJECT_MASTER_GUIDE.md.

Ao finalizar, execute o checkpoint entre fases, atualize o docs/PROJECT_STATUS.md e apresente os resultados.

Não avance automaticamente para a próxima fase.
```

Use o segundo prompt somente após revisar o diagnóstico e confirmar a fase. Respeite AGENTS.md, os gates financeiros e os recursos gerenciados pelo Lovable. Revise e sincronize as alterações no GitHub antes de iniciar outra fase.
